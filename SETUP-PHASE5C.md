# Phase 5C — Personal Android admin app

The Android project lives in the sibling folder:

**`nexus265-admin-app/`**

See that folder’s `README.md` for full install steps.

Summary:
1. Install Android Studio
2. `cd nexus265-admin-app && npm install && npx cap add android && npx cap sync android && npx cap open android`
3. Build APK → install on your phone
4. Battery → Unrestricted + notifications allowed
5. Login → enable chat alerts

No Play Store fee for personal sideload.
